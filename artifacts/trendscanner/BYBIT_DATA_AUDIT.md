# Проверка данных для Bybit

## Результат проверки 8 сентября 2026

Рабочий источник в `scanner.py` — `ccxt.kucoinfutures()`. Свечи поступают
в `multi_tf.py` из `get_data()` и затем в `analyze_timeframe()`.
Поэтому прошлые исследования на этом загрузчике относятся к данным KuCoin.

Попытка получить публичные рынки обеих бирж из среды разработки завершилась
`NetworkError`. Снимок запуска: [bybit_data_audit_2026-09-08.json](reports/bybit_data_audit_2026-09-08.json).
Статус — **BLOCKED**. Численное расхождение реальных свечей, доступность всех
контрактов и совпадение сигналов пока не установлены. Ошибка описывает доступ
из этой среды, а не работоспособность бирж для других пользователей.

## Подтверждённые различия

| Проверка | Текущий загрузчик | Bybit |
| --- | --- | --- |
| Целевой контракт | KuCoin Futures | Линейный бессрочный контракт с расчётом в USDT |
| 1h / 4h / 1d / 1w | Нативные интервалы адаптера KuCoin Futures | Нативные интервалы |
| 1M | Агрегация последних 500 дневных свечей | Нативный месячный интервал `M` |
| Незакрытая свеча | `get_data()` для обычных интервалов возвращает ответ API без фильтра закрытия | API может возвращать незакрытую свечу |

Интервалы и поведение незакрытых свечей описаны в [Bybit Get Kline](https://bybit-exchange.github.io/docs/v5/market/kline).
Виды контрактов доступны через [Bybit Instruments Info](https://bybit-exchange.github.io/docs/v5/market/instrument).
Дополнительно проверен исходный код установленного CCXT 4.5.66: у KuCoin
общая таблица `timeframes` включает spot-интервалы; для futures требуется
таблица `options.timeframes.swap`. Диагностика использует именно её.

## Воспроизводимый запуск

Из корня репозитория, с установленными зависимостями проекта:

```bash
python artifacts/trendscanner/exchange_data_audit.py \
  --output artifacts/trendscanner/reports/bybit_data_audit_latest.json
```

По умолчанию проверяются контракты из `config.SYMBOLS`; свечи запрашиваются
для BTC, ETH и SOL на пяти проектных таймфреймах. Параметр `--symbols`
позволяет расширить выборку. `--limit` задаёт число закрытых свечей (1–198),
`--as-of-ms` — общую временную границу. Без него время фиксируется один раз
перед запросами. Версия CCXT и параметры сохраняются в JSON вместе со свечами.

Скрипт использует публичные запросы с таймаутом 8 секунд, без ключей и ордеров.
Он проверяет точное имя рынка, active/swap/linear, базовый актив и USDT
в quote/settle; не подбирает похожие тикеры. Закрытие месяца считается
по календарю UTC. Незакрытые свечи исключаются; некорректные данные,
конфликтующие дубликаты, разрывы и устаревшие окна отражаются в отчёте.
OHLC сравниваются только при одинаковом времени открытия.

Объёмы двух площадок напрямую не сопоставляются: это разная торговая
активность и потенциально разные единицы. Месячная агрегация KuCoin требует
отдельного сравнения дневной истории; сейчас она явно помечается
`UNSUPPORTED_NATIVE_TIMEFRAME`, а не считается проверенной.

Код выхода 0 означает полный сбор запрошенных сравнений и успешную проверку
контрактов, 2 — `BLOCKED` или `PARTIAL`. `COMPARED` означает наличие измерения,
а не эквивалентность данных или доказанную пригодность стратегии.

Следующий этап после доступного запуска: проверить расхождения на сохранённых
свечах и месячную агрегацию, затем отдельно оценить изменение сигналов при
смене источника. Этот инструмент не запускает исторический replay.
